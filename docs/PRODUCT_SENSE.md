# Product Sense

The platform helps company and institution users access technology evaluation services through a customer-facing Front Office.

## Users

- Anonymous visitor
- Company member
- Institution member
- Company/institution representative
- Sub-account user

## Jobs To Be Done

- Understand available technology evaluation services.
- Start a mock self-diagnosis flow.
- Submit information-use consent.
- Track application progress in My Page.
- Let institution members review transmitted/submitted mock records.

## Decision Rule

When policy is missing, record an open question instead of inventing behavior.
