# Product Sense

## Vision

Provide a unified Front Office where companies and institutions can access technology evaluation services, track applications, manage consent, and view mock evaluation progress before production policies are confirmed.

## Target Users

- Anonymous visitor
- Company member
- Institution member
- Company or institution representative
- Sub-account user
- Future back-office operator/admin/evaluator

## Jobs To Be Done

- Understand available technology evaluation services.
- Log in through a mock role-based flow during early development.
- Start and track evaluation applications.
- Submit information-use consent where required.
- Let institution users review transmitted/submitted mock records.
- Access notices, references, Q&A, FAQ, related sites, and My Page.

## Decision Rule

If a policy is missing, record an open question instead of inventing behavior.
