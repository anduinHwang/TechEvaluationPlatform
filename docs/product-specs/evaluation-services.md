# Evaluation Services Requirements

Do not invent scoring formulas, grade thresholds, report types, paid/free policy, guarantee recommendation rules, Excel validation rules, or external transmission mechanisms.

## KTRS-FM

Anonymous users can access introduction and guide pages.

Company members need self-diagnosis application list, progress/result inquiry, application creation, company information input, technology information input, checklist, mock calculated result display, information-use consent, report view/print/download placeholders, and result transmission placeholder.

Institution members need individual evaluation list, company/business-number search, evaluation verification shell, consent document upload placeholder, report view/print placeholders, result verification page, guarantee recommendation placeholder, and bulk evaluation placeholders.

## TECH-INDEX

Anonymous users need introduction, guide, trend information, and trend dashboard with selectable target items and charts.

Company members need self-diagnosis, expert evaluation application, progress/result inquiry, information-use consent, report placeholders, and partner institution/bank transmission placeholder.

Institution members need individual evaluation, verification, report placeholders, bulk Excel upload/download placeholders, compressed HTML output placeholder, and cross-network integration placeholder.

## Source Technology Evaluation

Anonymous users need introduction and guide pages.

Company members need self-diagnosis, company/technology information, checklist, mock result display, consent, progress/result inquiry, report placeholders, and institution transmission placeholder.

Institution members need consent form upload placeholder, file server placeholder, electronic document repository placeholder, search, verification, guarantee recommendation placeholder, bulk Excel placeholders, and compressed HTML output placeholder.
