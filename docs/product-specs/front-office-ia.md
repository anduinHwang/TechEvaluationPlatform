# Front Office Information Architecture

## Overview

The Front Office is the customer-facing area of the Technology Evaluation Integrated Platform. It serves anonymous visitors, company members, institution members, representatives, and sub-account users.

Reference service: KIBO K-TOP Open Technology Evaluation Platform.

## User Types

- Anonymous visitor
- Company member
- Institution member
- Company or institution representative
- Sub-account user

## Global Navigation

- Open Technology Evaluation
- KTRS-FM
- TECH-INDEX
- Source Technology Evaluation
- Investment Model
- BIGx Report
- News / Notifications

## Screen Inventory

| Area | Screens and functions |
|---|---|
| Home | Anonymous main home, company member main home, institution member main home |
| Member/Auth | Login, ID login tab, certificate login tab, simple authentication tab, registration, company registration, institution registration, ID/password recovery, account recovery |
| Evaluation Services | KTRS-FM, TECH-INDEX, Source Technology Evaluation, Investment Model, BIGx Report |
| Common Pages | Notices, Reference Library, Q&A, FAQ, Related Sites |
| Consent | Information-use consent, required/optional consent items, electronic signature placeholder, consent history |
| My Page | Dashboard, profile, application progress, evaluation results, paid service management, notification settings, quick/favorites settings, sub-account management |
| Footer | Usage guide, privacy policy, copyright policy, related sites, address, directions, phone numbers, SNS links |

## Main Home

Anonymous home must expose a service introduction banner, key content, login/sign-up CTA, integrated search entry, help links, and dark mode toggle placeholder.

Company member home must expose recent evaluation status, quick/favorite menus, personalized settings, help links, integrated search, and service shortcuts.

Institution member home must expose evaluation counts, sub-account status summary, configured quick menus, personalized settings, help links, integrated search, and service shortcuts.
