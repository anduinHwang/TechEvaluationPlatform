# My Page Requirements

## Dashboard

My Page home must show integrated service application progress and detail navigation.

Menus:

- Edit member information
- Application status
- Progress status
- Evaluation results
- Application history
- Paid service application/management
- Notification settings
- Quick menu/favorites settings
- Sub-account management

## Application Progress

Must include KTRS-FM, TECH-INDEX general/startup, Source Technology Evaluation, Open Investment Model, and BIGx Report.

## Evaluation Result Detail Inquiry

Must include service application item, application date, key information, one-year period filter, submitted material download placeholder, and evaluation/report PDF download placeholder.

## Paid Service Management

Must include paid application list, service usage limit, information-use consent placeholder, billing/payment placeholder, one-year period filter, cancel subscription button, and apply button.

## Notification Settings

Must support SMS and Kakao notification consent toggles as placeholders until providers are confirmed.

## Quick Menu / Favorites

Must allow users to configure quick menus and favorite menus used on the home page.

## Sub-Account Management

Representatives must eventually create sub-IDs and manage permissions, approval status, activation status, latest login date, and work status. Permission enforcement and approval workflow are future mock/production work, not PR 0-1.
