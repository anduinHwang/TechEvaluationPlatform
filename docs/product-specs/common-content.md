# Common Content Requirements

## Notices

Must support notice list, search input, category filter, notice detail, file download placeholder, and PDF preview placeholder.

## Reference Library

Must support reference list, search input, category filter, reference detail, file download placeholder, and PDF preview placeholder.

## Q&A

Must support inquiry list, inquiry registration, search input, service category filter, answer status, inquiry detail, and administrator answer display.

Answer statuses:

- Received
- Under review
- Answered

## FAQ

Must show FAQ list and search input from admin-managed content.

## Related Sites

Must list related institutions and sites. Selected sites should open in a new window. Actual URL policy remains to be confirmed where not specified.

## Information-Use Consent

Must support consent body text, select-all checkbox, individual consent item list, electronic signature button placeholder, cancel, agree, consent history, and electronic signature history.

## Footer

Footer must include KIBO logo placeholder, usage guide, privacy policy, copyright policy, related sites, address, directions link, representative phone, night duty phone, SNS icons, and copyright text.
