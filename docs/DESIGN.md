# Design Guide

The Front Office should feel like a public-facing government/financial service: clear, restrained, trustworthy, and easy to scan.

## Current Slice

- Anonymous home presents service purpose and login CTA.
- Company dashboard emphasizes application progress and quick actions.
- Institution dashboard emphasizes reviewable evaluations and sub-account placeholders.
- Error states clearly identify mock API unavailability.
- Consent UI separates required consent from optional notification consent.
